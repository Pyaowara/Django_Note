## How to use cheatsheet

 1. Move finalCreate.bat to folder you want
 2. Use this command ./finalCreate.bat and folllow instruction
 3. Move `/management/commands` to your models.py directory
 4. Run everything then run `python manage.py CRUD` to get all models query in Markdown file
 5. Run `python manage.py aggre_anno` to get all Aggregate and Annotate function example in another Markdown file
